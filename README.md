## Description

This is my final year project. In collaboration with my project partner Shane Power we build a fullstack application. The purpose of this application is to allow you to perform Retrieval Augmented Generation on your many different data stores. The way it works is that you simply create a connector for you specific type of data store. The data store will be used by an agent to perform ingestion and embedding of your data. A different agent is then used query your data and generate you a response based on whatever prompt you give it. This fullstack application was developed with Next.js, FastAPI and the LangGraph framework. Our goal was to create a unified point of query for many different data stores. Intentionally also separating ingestion from response generation to reduce hallicinations.

If you have any further questions please refer to the `docs/` directory. In that directory you will find useful documentation in relation to how to set the application, and a more detailed breakdown of the system behind the application. You can also email me at `razvangorea7@gmail.com`.
