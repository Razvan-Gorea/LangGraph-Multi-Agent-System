## Description

This is my final year project. In collaboration with my project partner Shane Power we build a fullstack application. The purpose of this application is to allow you to perform Retrieval Augmented Generation on your many different data stores. The way it works is that you simply create a connector for you specific type of data store. The data store will be used by an agent to perform ingestion and embedding of your data. A different agent is then used query your data and generate you a response based on whatever prompt you give it. This fullstack application was developed with React.js, FastAPI and the LangGraph framework.

If you have any further questions please refer to the `docs/` directory. In that directory you will find useful documentation in relation to how to set the application up and a more detailed breakdown of the system behind the application.
